# A Little Time

A gentle personal reminder webpage for an HTML/CSS course assignment. It encourages small, manageable steps for editing photos, connecting with my parents, and replying to messages, while letting me decide when to begin.

## Open the page

Download or clone this project, then double-click `index.html` to open it in a web browser. Keep `styles.css` in the same folder. No installation or build step is needed.

## Files

- `index.html` contains the page structure, reminder cards, buttons, and task input.
- `styles.css` controls the colors, typography, spacing, responsive layout, and keyboard focus styles.

## Current scope

This is a static HTML/CSS layout prototype with no JavaScript, frameworks, or third-party dependencies. Timers, reminders, scheduling, and task breakdown are not implemented. The buttons are placeholders, and the photo-editing steps are a labeled example.

## Design process and AI assistance

I provided my personal needs and chose the design direction. AI helped generate the code. I later requested changing the general family card to a more specific parents card, with options to send a photo, leave a voice message, or plan a call.
